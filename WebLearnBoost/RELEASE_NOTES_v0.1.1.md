# WebLearnBoost v0.1.1 试用版说明

这是一版小更新，主要修复了：
- 原文依据定位更准确，减少弱匹配误跳转。
- content script 打包方式修正，避免 Chrome 扩展加载时报 `Cannot use import statement outside a module`。
- 扩展版本号、发布包名称同步更新到 `v0.1.1`。

## 下载与安装

1. 下载 `WebLearnBoost-v0.1.1.zip`。
2. 解压 zip。
3. 打开 `chrome://extensions` 或 `edge://extensions`。
4. 开启开发者模式。
5. 加载解压后的扩展程序。

其余安装与配置步骤保持不变，可继续参考 `INSTALL_FOR_TESTERS.md`。
