# WebLearnBoost 隐私说明

最后更新：2026-05-12

WebLearnBoost 是一个浏览器扩展试用版，用于把用户当前打开的网页或选中文本生成学习地图、训练题、本地历史记录和 Markdown 学习包。

## 会读取哪些数据

当你主动点击生成学习地图或训练内容时，扩展会读取：

- 当前网页标题
- 当前网页 URL
- 当前网页正文，或你选中的网页文本
- 用于回到原文的少量文本摘录

扩展不会在你没有触发生成流程时主动上传网页正文。

## 会保存哪些数据

以下内容保存在浏览器本地存储中：

- Provider 类型
- Base URL
- API Key
- Model 名称
- 输出语言
- 学习包历史
- 答题记录
- Markdown 导出状态

卸载扩展、清除浏览器数据或手动删除历史，可能会删除这些本地数据。

## 会发送到哪里

当你生成学习地图或训练内容时，扩展会把网页内容、选中文本、学习地图上下文和输出语言发送到你在设置中填写的 Base URL。

WebLearnBoost 不提供内置模型服务，也不会把内容发送到固定的第三方服务。实际请求目的地由你配置的 OpenAI Compatible 或 Anthropic Compatible 服务决定。

## API Key 如何使用

API Key 保存在浏览器本地，用于向你配置的 Base URL 发起模型请求。

请只填写你信任的服务地址。反馈问题时不要发送完整 API Key。

## 不会做什么

WebLearnBoost 不会：

- 收集完整浏览历史用于分析或广告
- 在未触发生成流程时上传网页正文
- 把 API Key、网页正文或学习历史发送到项目维护者的服务器
- 出售用户数据
- 用用户数据做广告定向

## 导出文件

Markdown 导出由用户主动触发。导出的文件会包含来源 URL、学习地图、摘要、练习题、答题标记和原文摘录。

## 联系与反馈

如果你在内测中发现隐私、权限或数据处理问题，请把问题现象、浏览器版本、操作步骤和截图发给项目维护者。不要发送完整 API Key。
