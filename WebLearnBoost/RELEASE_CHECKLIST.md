# WebLearnBoost 发布清单

本清单用于试用版打包和提交扩展商店前检查。发布前请确保源码、构建产物、截图、隐私说明和版本信息保持一致。

## 权限说明

当前 Manifest V3 权限需要逐项确认用途，并在商店说明或隐私材料中保持一致。

| 权限 | 用途 | 发布检查 |
| --- | --- | --- |
| `activeTab` | 获取用户当前主动操作的标签页，用于读取当前网页内容并生成学习包。 | 只在用户打开侧边栏或点击生成时使用。 |
| `scripting` | 在当前网页缺少内容脚本连接时，按需注入 `content.js` 以完成正文提取和原文定位。 | 只注入到可访问的普通网页。 |
| `storage` | 保存 Provider 设置、API 配置、本地学习包历史和答题进度。 | 不把本地历史用于无关用途。 |
| `sidePanel` | 在浏览器侧边栏提供主界面。 | 侧边栏路径指向构建后的 `index.html`。 |
| `tabs` | 查询当前标签页标题、URL，切换或打开来源页以定位原文依据。 | 不读取无关窗口或后台标签内容。 |
| `<all_urls>` | 允许内容脚本在用户访问的普通网页上提取正文，支持不同站点的学习场景。 | 商店说明需解释广泛主机权限的必要性。 |

## 隐私检查

- [ ] 隐私说明写明扩展会读取用户主动访问网页的标题、URL、正文或选中文本。
- [ ] 隐私说明写明学习包历史、答题记录和 Provider 配置保存在浏览器本地存储。
- [ ] 隐私说明写明 API Key 保存在本地，并只用于请求用户配置的 Base URL。
- [ ] 隐私说明写明网页内容会发送到用户配置的模型兼容接口以生成学习内容。
- [ ] 不收集与学习包生成无关的浏览历史。
- [ ] 不在未触发生成流程时上传网页正文。
- [ ] 不把 API Key、网页正文或历史记录写入远程日志。
- [ ] 错误提示不展示完整 API Key。
- [ ] 导出的 Markdown 由用户主动触发下载。

## 图标与商店素材

- [ ] Manifest 配置扩展图标，至少覆盖商店和浏览器工具栏需要的常见尺寸。
- [ ] 图标在浅色和深色浏览器主题下可识别。
- [ ] 扩展管理页名称、描述、版本号显示正常且无乱码。
- [ ] 准备至少一张展示侧边栏主流程的截图。
- [ ] 准备学习地图、训练题、历史或导出相关截图。
- [ ] 截图不包含真实 API Key、个人账号、内部 URL 或敏感网页内容。
- [ ] 商店简介准确描述试用版能力和限制。

## 版本号与 Manifest

- [ ] `package.json` 版本号与 `public/manifest.json` 版本号一致。
- [ ] Manifest 描述文案准确、无乱码、无测试占位文本。
- [ ] Manifest 权限列表与实际代码用途一致。
- [ ] 不包含未使用或无法解释的权限。
- [ ] `manifest_version` 为 3。
- [ ] `background.service_worker`、`side_panel.default_path` 和 content script 路径与构建产物一致。
- [ ] 发布分支或发布包不包含本地调试配置、测试密钥或临时日志。

## 构建与打包

- [ ] 清理旧的 `dist` 目录或确认不会混入过期文件。
- [ ] 运行 `npm install` 或确认依赖锁文件已同步。
- [ ] 运行 `npm run typecheck` 通过。
- [ ] 运行 `npm test` 通过。
- [ ] 运行 `npm run build` 通过。
- [ ] 在扩展管理页加载 `dist` 后完成手动测试清单中的核心路径。
- [ ] 打包 `dist` 目录内容，而不是仓库根目录。
- [ ] 压缩包中包含 manifest、脚本、HTML、CSS、资源和图标。
- [ ] 压缩包中不包含源码映射、测试文件、未使用的大文件或敏感文件，除非发布策略明确允许。

## 商店发布检查

- [ ] 扩展名称、简短描述、详细描述与实际功能一致。
- [ ] 权限用途说明覆盖 `activeTab`、`scripting`、`storage`、`sidePanel`、`tabs` 和 `<all_urls>`。
- [ ] 隐私政策或隐私声明链接可访问。
- [ ] 支持邮箱、问题反馈入口或项目主页可访问。
- [ ] 分类、语言、地区和目标用户选择正确。
- [ ] 截图尺寸、格式和内容符合商店要求。
- [ ] 发布说明包含本次试用版新增能力、已知限制和升级注意事项。
- [ ] 若商店要求远程代码说明，确认构建产物不依赖未声明的远程脚本。
- [ ] 若商店要求数据用途申报，申报内容与隐私检查一致。
- [ ] 提交前使用全新浏览器用户资料加载发布包复测首次安装流程。

## 发布后验证

- [ ] 从商店安装发布版本。
- [ ] 首次打开、设置保存、整页生成、选区生成、训练、历史和导出均可用。
- [ ] 权限提示与商店说明一致。
- [ ] 更新旧版本后，本地设置和历史仍可读取。
- [ ] 记录发布版本号、发布时间、审核状态和已知问题。
