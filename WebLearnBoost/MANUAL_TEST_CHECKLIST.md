## 首次安装

- [ ] 运行 `npm install` 成功。
- [ ] 运行 `npm run build` 成功生成 `dist`。
- [ ] 浏览器开发者模式可加载 `dist` 目录。
- [ ] 扩展名称、描述、版本号在扩展管理页可见且无乱码。
- [ ] 点击扩展入口后，侧边栏能打开。
- [ ] 首次打开时未配置 API Key 的提示清晰可见。
- [ ] 设置页能保存 Provider、Base URL、API Key、Model 和输出语言。
- [ ] 重新打开侧边栏后，设置仍然保留。

## 整页生成

- [ ] 打开普通 `https://` 文章页。
- [ ] 选择整页模式。
- [ ] 点击生成学习地图。
- [ ] 页面标题、URL、摘要或来源信息正确显示。
- [ ] 学习地图包含概览、结构、概念、关系、阅读顺序、易错点和前置知识。
- [ ] 生成过程中按钮进入忙碌/禁用状态，避免重复提交。
- [ ] 生成完成后可以进入训练页。
- [ ] 刷新来源网页后重新生成仍然可用。

## 选区生成

- [ ] 在网页正文中选中一段连续文本。
- [ ] 选择选中段落模式。
- [ ] 点击生成学习地图。
- [ ] 学习包标记为选区来源。
- [ ] 生成内容只围绕选中的文本，不混入明显无关的整页内容。
- [ ] 取消选区后再次使用选区模式，会给出可理解的空内容或读取失败提示。
- [ ] 选区内容较短时，界面仍能完成或给出清楚的失败原因。

## Provider：OpenAI Compatible

- [ ] Provider 选择 OpenAI Compatible。
- [ ] Base URL、API Key、Model 保存成功。
- [ ] 整页模式可生成学习地图。
- [ ] 训练内容可生成摘要、练习题、解释和原文依据。
- [ ] API Key 错误时，界面显示失败状态和恢复建议。
- [ ] Model 名称错误时，界面显示失败状态，不会卡在加载中。
- [ ] Base URL 不可访问时，界面显示网络或请求失败信息。

- [ ] Base URL、API Key、Model 保存成功。
- [ ] 整页模式可生成学习地图。
- [ ] 选区模式可生成学习地图。
- [ ] 训练内容可生成摘要、练习题、解释和原文依据。
- [ ] API Key 错误时，界面显示失败状态和恢复建议。
- [ ] Model 名称错误时，界面显示失败状态，不会卡在加载中。

## 训练

- [ ] 有学习地图但未生成训练内容时，训练页显示生成入口。
- [ ] 点击生成训练内容后，摘要列表正常显示。
- [ ] 自测题显示题号、选项和答题进度。
- [ ] 选择正确答案时显示正确反馈和解释。
- [ ] 选择错误答案时显示错误反馈、解释和重试引导。
- [ ] 答对后自动前进或导航按钮状态符合预期。
- [ ] 上一题/下一题按钮不会越界。
- [ ] 已答答案会保存到当前学习包。
- [ ] 原文依据按钮能定位或切换回来源页面；无法定位时有错误提示。

## 历史

- [ ] 生成训练内容后，学习包写入本地历史。
- [ ] 历史按 URL 分组，并显示版本数量。
- [ ] 同一网页重复生成会形成多个版本。
- [ ] 可以打开历史中的旧版本。
- [ ] 打开旧版本后摘要、题目、答案状态和来源信息保持一致。
- [ ] 删除单个历史版本成功。
- [ ] 删除后列表数量和分组状态更新正确。
- [ ] 无历史时显示空状态。

## 导出

- [ ] 有训练内容的学习包可以导出 Markdown。
- [ ] 导出后浏览器触发下载。
- [ ] 文件名包含学习包标题和日期，且不包含非法文件名字符。
- [ ] Markdown 包含来源 URL、创建时间和输入范围。
- [ ] Markdown 包含学习地图、摘要、练习题、答案标记和原文摘录。
- [ ] 导出失败时显示错误提示，不影响当前学习包。

## 错误场景

- [ ] 在浏览器内部页面打开侧边栏时，读取失败提示清楚。
- [ ] 在扩展商店或受限页面打开侧边栏时，读取失败提示清楚。
- [ ] 在空白页、无正文页或极短页面生成时，有空内容或质量不足提示。
- [ ] 断网时生成失败，不会无限加载。
- [ ] Base URL 填写非法地址时，保存或生成阶段有可理解反馈。
- [ ] API Key 留空时，入口页会提示先配置。
- [ ] 服务返回非 JSON、超时或权限错误时，界面显示失败状态。
- [ ] 快速连续点击生成按钮不会产生重复学习包或界面错乱。
- [ ] 切换标签页后继续操作，来源不一致时有明确提示。
- [ ] 清除浏览器本地数据后，设置和历史表现符合首次安装状态。
