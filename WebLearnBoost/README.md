# WebLearnBoost

WebLearnBoost 是一个浏览器扩展试用版，用于把当前网页或选中文本转成学习地图、训练题、本地历史记录和可导出的 Markdown 学习包。

## 本地安装

环境要求：

- Node.js 18 或更新版本
- 支持 Manifest V3、侧边栏扩展和开发者模式的 Chromium 系浏览器

安装依赖：

```powershell
npm install
```

## 本地构建

生成可加载的扩展产物：

```powershell
npm run build
```

构建成功后，扩展文件位于 `dist` 目录。

常用检查命令：

```powershell
npm run typecheck
npm test
```

## 加载扩展

1. 打开浏览器的扩展管理页。
2. 开启开发者模式。
3. 选择“加载已解压的扩展程序”。
4. 选择本仓库构建生成的 `dist` 目录。
5. 打开一个普通 `http://` 或 `https://` 网页。
6. 点击 WebLearnBoost 扩展入口，在侧边栏中开始使用。

如果修改了源码，请重新运行 `npm run build`，然后在扩展管理页点击重新加载。

## 配置模型 Provider

首次使用前，打开 WebLearnBoost 侧边栏中的设置页，填写 Provider、Base URL、API Key、Model 和输出语言。配置会保存到浏览器本地存储。

### OpenAI Compatible

适用于实现 OpenAI 风格接口的模型网关或本地服务。

- Provider：选择 `OpenAI Compatible`
- Base URL：填写兼容接口的根地址，通常以 `/v1` 结尾
- API Key：填写该服务要求的访问密钥；如果本地服务不需要密钥，可按服务约定填写占位值
- Model：填写该服务暴露的模型名称
- 输出语言：填写期望的学习包语言，例如 `中文`

### Anthropic Compatible

适用于实现 Anthropic 风格接口的兼容服务。

- Provider：选择 `Anthropic Compatible`
- Base URL：填写兼容接口的根地址
- API Key：填写该服务要求的访问密钥
- Model：填写该服务暴露的模型名称
- 输出语言：填写期望的学习包语言

不同兼容服务对路径、鉴权头、模型名和流式响应的支持可能不同。若生成失败，请先确认该服务的兼容接口、密钥权限和模型名称可用。

## 基本使用流程

1. 打开要学习的网页。
2. 在侧边栏入口选择“整页”或先在网页中选中文本后选择“选中段落”。
3. 生成学习地图。
4. 生成训练内容。
5. 完成自测题，查看解释和原文依据。
6. 在历史中重新打开学习包，或导出 Markdown。

## FAQ

### 为什么读取不到网页？

扩展只能注入普通 `http://` 和 `https://` 页面。浏览器内部页面、扩展商店页面、PDF 查看器、受限页面或尚未刷新过的页面可能无法读取。请换到普通网页、刷新页面后重试，或选中正文段落后再试。

### 为什么选区模式没有内容？

请先在网页正文中选中可复制文本，再回到侧边栏点击生成。部分网页会阻止选择或把正文放在特殊容器中，这种情况下可以改用整页模式。

### API Key 会上传到哪里？

API Key 保存在浏览器本地存储中，用于向你配置的 Base URL 发起生成请求。请只填写你信任的兼容服务地址。

### 历史记录保存在哪里？

学习包历史、回答进度和设置保存在浏览器本地存储中。卸载扩展、清除浏览器数据或手动删除历史可能会移除这些内容。

### 导出的文件是什么格式？

导出文件是 Markdown，包含来源、学习地图、摘要、练习题、回答标记和原文摘录。

### 修改代码后为什么看不到变化？

请重新运行 `npm run build`，然后到扩展管理页重新加载已解压扩展。必要时刷新正在测试的网页。
